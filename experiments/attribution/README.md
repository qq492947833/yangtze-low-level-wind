# Regional-mean expected gradients

Fig. 13 attributes the first-stage physical wind forecast to its three surface inputs. Fig. S20 attributes the second-stage residual correction to its twelve inputs. The forward function converts each output to physical units and averages over the fixed rectangular model domain. For each output and predictor, sum the signed attributions over six lags and all input cells before taking the absolute value. The plotting notebook averages these magnitudes over the 100 samples and six leads and normalizes across predictors for that output.

Run the following steps with the model weights and scalers from the same training run. All paths below are examples. Set `YANGTZE_MODEL_DIR`, `YANGTZE_DATA_DIR`, `YANGTZE_RESULTS_DIR` and `YANGTZE_DEVICE` before running the commands from this directory.

1. Run `python sample_inputs.py --output samples.npz` once. It intersects initialization times over all six leads separately for the training and test pools. The original sampling order draws 100 background times from training, then 100 example times from testing, without replacement, using NumPy seed 25. The file also contains each example's eleven hourly ERA5 inputs, its six target times, and the fixed regional mask.
2. Run `python prepare_inputs.py --raw samples.npz --weights STAGE1_WEIGHTS --normalization LEAD_SCALER --output prepared_lead1.npz` for each lead. Six first-stage forecasts form the prediction channels for the residual network. The residual attribution treats those channels as fixed inputs.
3. For each stage (1–2), lead (1–6) and sample (0–99), run e.g. `python stagewise.py --stage 1 --lead 1 --sample 0 --weights STAGE1_WEIGHTS --normalization LEAD_SCALER --inputs prepared_lead1.npz --blocks blocks`. Supply that lead's stage-specific weights. Nested integration prefixes start at 2,048 and 4,096 draws. Each output retains its first estimate meeting the efficiency, elementwise convergence, feature-share and rank criteria in [quality.py](quality.py).
4. For both stages run `python assemble_importance.py --stage 1 --blocks blocks --samples samples.npz --results RESULTS_DIR`, using the same results directory as the [plotting notebook](../../figures/Fig13_S20_shap_importance.ipynb). The assembler requires all 600 converged blocks for that stage and writes its figure-input NetCDF. Its variables cover the inputs needed by Figs. 13 and S20.
