# Forecast baselines and additional experiments

Run the commands from the repository root. Set `YANGTZE_DATA_DIR` to the hourly ERA5 input directory and `YANGTZE_WORK_DIR`, `YANGTZE_MODEL_DIR` and `YANGTZE_RESULTS_DIR` to the working, model and prediction directories. Absolute paths keep these locations consistent across notebook kernels. Replace lead 1 in the examples with any lead from 1 to 6 h.

| Experiment | Run order and inputs |
| --- | --- |
| Shared ERA5 arrays | Run `python experiments/gradient/gradient_pipeline.py --stage cache` once before Ridge, ZWD or gradient training. It reads three surface fields and nine wind fields and writes aligned arrays and coordinates under `YANGTZE_WORK_DIR/gradient/source_cache`. |
| Persistence | The preparation notebook `figures/prepare_Fig7_S13_baseline_scores.ipynb` constructs persistence from the test observations for each lead. Its `nc_path` returns that lead’s reference wind file. `scan_inputs` assigns the observation at initialization to the target hour by adding the lead, then intersects the comparison time axes. |
| Local Ridge | `python experiments/ridge/run_ridge.py --lead 1` fits each grid point using 11 hours of three surface variables in a 3 × 3 neighborhood. Add `--extended` for four smaller positive penalties and an OLS diagnostic. Each lead uses its validation-selected penalty across all grid points and nine outputs. The exported vertical component is pressure velocity in Pa s⁻¹. |
| Gradient inputs | `python experiments/gradient/gradient_pipeline.py --lead 1 --stage both` trains the gradient-augmented first stage, then the residual stage. The first stage adds the eastward, northward and temporal derivatives of each surface channel. |
| Variational mode decomposition | Run `experiments/vmd/decompose.ipynb` to produce split-specific intrinsic mode functions, then `experiments/vmd/train_residual.ipynb`. Set `YANGTZE_LEAD` for training. `YANGTZE_VMD_DIR` defaults to `YANGTZE_WORK_DIR/vmd`. Training expects five pressure modes, six temperature modes and six dew-point modes. |
| Zenith wet delay | Point `YANGTZE_ZWD_FILE` to an hourly NetCDF containing `ZWD`, `zwd_available`, `time` (hours since 1970-01-01), `latitude` and `longitude`. Run `python experiments/zwd/prepare_zwd.py`. For each lead run `python experiments/zwd/train_zwd.py train --lead 1 --arm A --stage 1`, then B stage 1, A stage 2 and B stage 2. A uses the three surface fields. B adds ZWD to the first stage. After both stages and all six leads, run `python experiments/zwd/compare_zwd.py` for paired metrics and block-bootstrap intervals. |
| Expected gradients | Follow [the stagewise attribution instructions](attribution/README.md) for training backgrounds, test sampling, stage inputs, nested-prefix convergence, figure-input assembly and plotting. Fig. 13 explains the first-stage forecast and Fig. S20 explains the residual correction. |
| Mechanism diagnostics (Fig. 12 and Figs. S16–S19) | Under `experiments/mechanisms/`, run `pinn/continuity.py` with the paired seeds’ no-PINN and no-shear PINN forecasts and surface pressure. Run `python experiments/mechanisms/gradient/case_scores.py --all` to calculate the gradient regimes, common target times, 36 per-case scores and paired cross-stage intervals. For stage 1, the 1–5 h zonal-wind cases use the common ERA5 reference; the remaining 13 stage-1 cases and all 18 stage-2 cases use their saved references with discrepancy bounds. `vmd/timescale.py` uses ERA5 and the original/VMD first-stage and final forecasts on 25 fixed grid points. These programs write the three NetCDF inputs for `figures/Fig12_S16_S19_mechanisms.ipynb`. |

`YANGTZE_DEVICE` selects the PyTorch device for gradient training, VMD residual training, ZWD training and attribution. The decomposition notebook exposes its CPU and CUDA settings in the first cell. Ridge runs on CPU.

### Training statistics and mechanism inputs

VMD searches the candidate mode counts and penalties on the training segment in physical units. The decomposition code mirrors each split’s raw signal for the Fourier transform. It checks the series variance when selecting usable grid points. The forecasting notebook then fits a mean and standard deviation for each mode and grid point on unique input hours covered by retained training windows. The three surface inputs use those training hours, and the nine wind targets use the matching window-end labels. Validation and test use the stored input and label statistics.

The gradient experiment derives eastward and northward differences from the physical surface fields and temporal differences within each six-hour window. Its nine derivative channels share per-grid statistics across the six positions of training windows. In both the VMD and gradient corrections, the second stage keeps the three surface predictors on their first-stage training scale, fits the nine forecast-input scalers on its own training input hours, and fits the residual-label scalers on its training targets. The final wind is the first-stage forecast plus the inverse-transformed residual.
